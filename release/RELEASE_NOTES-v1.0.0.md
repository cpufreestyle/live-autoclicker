# v1.0.0 · 直播按钮自动点击器（Windows x64）

对屏幕上多个直播窗口持续扫描，识别不定时弹出的「签到」「奖券」「领取」「兑换券 / 立即领券」等按钮，
命中后自动点击一次。**模板匹配 + OCR 双通道**：按钮样式固定用截图模板最稳，按钮会变但文字不变用 OCR 关键词。

> 合规提示：自动点击可能违反部分直播平台的服务条款，存在账号风控风险。请自行确认规则后再使用。

## 下载

`LiveAutoClicker-v1.0.0-win64.zip`（约 81 MB），解压后**整个文件夹随便放**，双击 `LiveAutoClicker.exe` 即用。

- 不需要装 Python，运行时、OCR 模型、OpenCV 全部打包在内。
- 只支持 **Windows 10/11 x64**。
- 配置和模板在 exe 旁边的 `config\` `templates\` 里，可直接手改，运行中约 0.2 秒自动生效。
- 日志写在同目录 `logs\run.log`。
- 绿色软件：只往自己的目录写文件，不装服务、不加开机启动项。

## 功能

- **多窗口同时监控**：每个窗口独立一条扫描线程、独立一行统计，停止互不影响。
- **按窗口身份实时跟随**（推荐）：微信直播间、浏览器直播间都能跟；挪位置、改大小、换直播间都不用重新框选；
  同身份多窗口粘性续跟不来回跳，且每次点击前按窗口最新位置校正偏移——OCR 那一两秒里窗口被拖动也点得中。
- **两种定位方式**：按窗口身份自动跟随，或框选一片区域（比全屏快得多）；两项都留空 = 整屏扫描。
- **双通道识别**：模板匹配（截图即用）+ OCR 关键词（文字不变即可），任一命中即点，每个目标可同时配两者。
- **每目标、每窗口独立冷却**，同弹窗里的第二个目标也不会被连点两下（同弹窗防重复，`click_guard_sec`）。
- **后台抓窗**：窗口被遮住、甚至最小化也能扫到；命中后被挡住会把窗口临时顶到前台再点，点完还原层次。
- **画面近乎不变时自动跳过本轮识别**，画面一变立刻恢复，不漏点也不白烧 CPU。
- **OCR 可选显卡**：装了 `onnxruntime-directml` 就自动走 GPU，真机同一档位 1501ms → 819ms，文字召回一致；没装照旧 CPU，行为完全不变。
- **点击前确认窗口还活着**，直播间被关掉时安静跳过，不误点桌面。
- **界面 / CLI / 配置文件**三种入口；改配置热生效，无需重启。
- 全局热键 `F1` 启动 / 停止；误点时把鼠标猛甩到屏幕左上角可中断（pyautogui 保险丝）。

## 自带的命令行自检

`selftest.py` 不开 GUI 就能调参：

- `--windows` 列屏幕上的窗口标题 / 类名 / 进程名，用来挑跟随关键字
- `--pick --write` 鼠标挪到直播窗口上停好别动，5 秒后自动识别身份并写回配置
- `--ocr-only` 打印识别到的全部文字与坐标，用来定关键词
- `--image shot.png` 用一张截图离线测检测逻辑，不碰真实屏幕
- `--ocr-bench` 扫几档 `ocr_max_side` 报耗时与文字召回，选速度折中点

## 从源码跑

需要 Python 3.10+（64 位），实测通过：Windows + Python 3.14 + numpy 2.4 / opencv 4.13 / mss 10.2 / rapidocr-onnxruntime 1.2.3。

```bat
pip install -r requirements.txt
python app.py
```

打包成自己那份：`build.bat`（PyInstaller onedir；`config/`、`templates/`、`assets/` 会复制到 exe 旁边）。
回归测试：`test_offline.py`（44 项，纯离线，不碰真实屏幕）。

## 界面窗口

默认 **880x640**（按 96 DPI 设计，随系统 DPI 同比放大），最小 **870x600**，一屏能看全。
拖动过的尺寸**会记住**：下次打开按你的来（存在 `config/ui.yaml`，删掉就恢复默认）。

下限不是随手定的——五个按钮平铺一行要 405/411px、按钮目标表合计 462px，比这再窄，
要么最后一个按钮被 Tk 压成 1px「隐形」，要么表的最右一列被裁掉。启动时程序会自己量一次，
窗口偏窄就在日志里提醒，功能本身不受影响。

## 常用参数

| 参数 | 说明 |
| --- | --- |
| `scan_interval_sec` | 单窗口扫描间隔，默认 1.5s |
| `ocr_threads` | 一次 OCR 能用几个线程，默认 4（这几个 PP-OCR 模型很小，线程开多了反而更慢） |
| `ocr_scan_every` | 隔几轮跑一次 OCR，默认 1（每轮都跑） |
| `ocr_idle_every` | 连续空轮后 OCR 改为隔 N 轮跑，一有命中立刻恢复，默认 2 |
| `ocr_provider` | `auto` / `cpu` / `directml`，默认 `auto`；推理会话建好就换不了，改完要先停止再启动 |
| `click_guard_sec` | 同弹窗防重复：点过一发后附近多少秒内不再点第二下，默认 2.0s，填 0 关闭 |
| `raise_before_click` | 命中点被别的窗口盖着时把监控窗口临时顶到前台再点，默认 `true` |

完整参数与调优说明见仓库里的 [README.md](https://github.com/cpufreestyle/live-autoclicker/blob/main/README.md)。
